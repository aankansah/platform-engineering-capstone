1. Access your services inside the cluster:

  kubectl get services -n {{ .Release.Namespace }}

2. Port-forward the Task Dashboard locally:

  kubectl port-forward -n {{ .Release.Namespace }} svc/task-dashboard 3000:3000

3. Open the application in your browser:

  http://127.0.0.1:3000

4. Check the status of all workloads:

  kubectl get pods -n {{ .Release.Namespace }}
  kubectl get svc -n {{ .Release.Namespace }}
  kubectl get hpa -n {{ .Release.Namespace }}

5. View logs for a specific service:

  kubectl logs -n {{ .Release.Namespace }} deploy/task-dashboard -f
  kubectl logs -n {{ .Release.Namespace }} deploy/task-gateway -f
  kubectl logs -n {{ .Release.Namespace }} deploy/task-validator -f
  kubectl logs -n {{ .Release.Namespace }} deploy/task-enricher -f

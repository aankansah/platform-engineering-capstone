1. Access your services inside the cluster:

  kubectl get services -n {{ .Release.Namespace }}

2. Port-forward the JavaScript API locally:

  kubectl port-forward -n {{ .Release.Namespace }} svc/javascript-api 8080:80

3. Open the application in your browser:

  http://127.0.0.1:8080

4. Check the status of all workloads:

  kubectl get pods -n {{ .Release.Namespace }}
  kubectl get svc -n {{ .Release.Namespace }}
  kubectl get hpa -n {{ .Release.Namespace }}

5. View logs for a specific service:

  kubectl logs -n {{ .Release.Namespace }} deploy/javascript-api -f
  kubectl logs -n {{ .Release.Namespace }} deploy/java-service -f
  kubectl logs -n {{ .Release.Namespace }} deploy/rust-processor -f
